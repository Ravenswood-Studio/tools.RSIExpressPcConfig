1. Follow the Windows 11 install process until you get to the "choose a country" screen. 

2. Hit SHIFT + F10

3. Type OOBE\BYPASSNRO to disable the Internet connection requirement.

4. The computer will reboot and return you to the same screen.

5. Hit Shift + F10 again and this time Type ipconfig /release

6. Finish install

7(Optional). After install if your having issues getting onto a network.
	A. Open CMD
	B. Type: ipconfig /release
	C. Type: ipconfig /renew
